Polypane Helper

The Polypane button and overlays help you quickly open the current page in Polypane.

Default behavior

The Polypane helper extension has a few always-available ways of opening Polypane.

  • Clicking the extension button will open Polypane with the current tab URL.
  • Pressing Alt/Option P will open Polypane with the current tab URL.
  • Right-click links and selecting "Open in Polypane" will open Polypane with the link URL.

Overlay behavior

The helper adds a button to local URLs. You can configure additional rules for specific domains.

  • Button A small button will appear in one of the page corners. Clicking it will open the Polypane overlay.

    Can be minified by pressing the > that pops out on hover, and its setting is remembered.
  • Overlay The Polypane overlay will automatically open when the page loads, showing an auto-focused "open in Polypane" button (press Enter to apply).

    Can be dismissed by pressing Esc or the × button
  • Auto-open Polypane will automatically be opened when the page loads, or after a specified delay.

    Can be dismissed by pressing Esc or the × button.
